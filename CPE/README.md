# CPE — Solved Problems Index

Problems are organized by difficulty (`easy/`, `medium/`) and then by category
(`io`, `repetition`, `selection`, `function`, `ad_hoc`, `control_flow`, `array`).

> Problem links follow the standard onlinejudge.org PDF path
> (`https://onlinejudge.org/external/<id/100>/<id>.pdf`). If a link ever 404s,
> search the ID directly on [onlinejudge.org](https://onlinejudge.org) or
> [uhunt](https://uhunt.onlinejudge.org/).
